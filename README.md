# Python Data Cleaning — Practice Notebook

A small learning repository for practising practical data-cleaning techniques in Python using Jupyter notebooks and sample datasets.

## Contents

- `Data Cleaning Tutorial - Real Python.ipynb` — a worked notebook based on a Real Python data-cleaning tutorial.
- `Datasets/` — sample data used by the notebook.

## Skills demonstrated

The notebook focuses on common data-preparation tasks such as:

- Loading and inspecting datasets.
- Identifying inconsistent or missing values.
- Cleaning text and numeric fields.
- Normalising data into more useful structures.
- Preparing datasets for downstream analysis.

## Getting started

A typical local setup is:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install jupyter pandas numpy
jupyter notebook
```

Then open the notebook from the Jupyter interface.

## Repository context

This is a **learning/practice repository** based on external tutorial material. It is retained to demonstrate Python data-wrangling exercises rather than presented as an original data-cleaning framework.
